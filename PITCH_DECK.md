## Slide 2: The Problem & Real-World Context

### The Scholarship Drop-Off Gap
- **Billions Unclaimed**: Every year, statutory scholarships go uncollected due to procedural abandonment.
- **Legacy Form Fatigue**: Applications require navigating 10–20 page legacy ASP.NET/JSP wizards with zero REST APIs.
- **Format Obstacles**: Rigid document size limits, dynamic dropdown cascades, and legal jargon create high barriers for first-generation college students.

---

## Slide 3: The Solution & Key Features

### Autonomous Public Bureaucracy Agent
1. **Pre-flight Document Intelligence**: Multimodal OCR extracts GPA, roll number, and family income before browser launch to guarantee 100% application sufficiency.
2. **Live Open Data Integration (Zero Dummy Data)**: Queries `data.gov.in` and statutory catalogs dynamically to match students against active quotas.
3. **Resilient Browser Execution**: Playwright automation engine equipped with Gemini ReAct planning, anti-bot micro-cadence (40–85ms jitter), and modal obstacle solvers.
4. **Human-in-the-Loop (HITL) Gate**: Explicit pause on statutory declarations for HTML5 canvas digital signature.
5. **Cryptographic Proofs**: Generates SHA-256 tamper-evident tracking receipts with PDF export.

### Key Technical Innovations
- **Vision Grounding Fallback**: When unmapped form elements appear, Gemini Vision locates normalized coordinates to click buttons and select dropdowns.
- **Pre-Submission Self-Reflection**: Verifies interactive DOM fields against statutory rules before committing intent.

## Slide 5: Strict Compliance & Zero Dummy Data

- **Zero Dummy Data (Zero-Tolerance Policy)**:
  - Queries active SQLite database continuously synced with official `data.gov.in` statutory feeds.
  - Generates verifiable SHA-256 cryptographic sync digests for every catalog query.
  - Zero hardcoded mock scholarship arrays in frontend client code.
- **Live Execution Security**:
  - PII masking on citizen phone, email, and national IDs in public telemetry logs.
  - Tamper-evident SHA-256 tracking receipts for auditability.
